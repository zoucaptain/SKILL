# 2. 超导导体与复合结构

> 来源：南和礼《超导磁体设计基础》第3-4章；王秋良《高磁场超导磁体科学》第2-3章

## 2.1 实用超导导体的基本要求

用于磁体的超导导体必须同时满足：
1. **高临界电流密度** Jc — 在运行磁场和温度下仍保持足够大的载流能力
2. **良好的稳定性** — 能承受热扰动和电磁扰动而不失超
3. **足够的机械强度** — 承受运行中的电磁力和热应力
4. **可加工性** — 能制成长线材并绕制成线圈
5. **经济可行性** — 成本和产量满足工程需求

## 2.2 NbTi 导体

### 材料特性
- **Tc ≈ 9.2 K**，**Bc2(4.2K) ≈ 15 T**
- 最高实用磁场：~10 T（4.2K 下）
- FCC 结构，固溶体合金，**钛含量 46-50 wt%**
- **优良延展性**：可直接拉丝加工

### 制造工艺（南和礼重点）
```
Nb + CuNi (或纯 Cu) 管坯
  → 装入 NbTi 棒
  → 拉拔 + 中间退火 (反复多次)
  → 最终尺寸线材
  → 时效处理 (375-400°C, 数百小时)
```

**关键工艺参数**：
- **时效处理**：析出 α-Ti 相（钉扎中心），显著提高 Jc
- **加工率**：总截面缩减率 > 99%，细丝尺寸达几微米
- **铜比**（Cu/SC 比）：通常 1:1 到 3:1，影响稳定性和载流能力

### Jc 特性
在 5T、4.2K 下，工程 Jc 典型值：2000-3000 A/mm²（含铜截面）。

## 2.3 Nb₃Sn 导体

### 材料特性
- **Tc ≈ 18.2 K**，**Bc2(4.2K) ≈ 30 T**
- 最高实用磁场：~20 T（4.2K 下）
- A15 晶体结构，**脆性化合物**（不可直接拉丝）

### 制造工艺 — 青铜法（Bronze Route）
```
Nb 棒 + Cu-Sn 青铜基体
  → 组装成复合坯料
  → 拉拔至最终尺寸
  → 热处理 (650-700°C, 数十至数百小时)
  → Sn 从青铜扩散至 Nb 表面形成 Nb₃Sn 层
```

### 制造工艺 — 内锡法（Internal Tin）
```
Nb 管 + Sn 芯 (或 Sn-Cu 合金)
  → 组装 + 拉拔
  → 热处理扩散反应
```

### 关键挑战
- **脆性**：反应后不可弯曲，必须先绕制后热处理（wind-and-react）
- **应变敏感性**：ε > 0.3% 时 Jc 显著下降
- **热膨胀失配**：热处理后冷却产生残余应力
- **铜比**：通常 1:1 到 2:1

## 2.4 复合超导导体结构

实用超导线采用**铜基复合结构**：

```
┌─────────────────────────────┐
│    铜基体 (高纯无氧铜)       │  ← 稳定化、保护、散热
│  ┌───┐ ┌───┐ ┌───┐ ┌───┐   │
│  │SC │ │SC │ │SC │ │SC │   │  ← 超导细丝 (NbTi/Nb₃Sn)
│  └───┘ └───┘ └───┘ └───┘   │
└─────────────────────────────┘
```

### 铜基体的三重功能

1. **热稳定化（Thermal Stabilization）**
   - 超导细丝局部失超 → 电流转移至铜 → 避免热点扩大
   - 要求：铜的稳态载流能力 > 超导态工作电流

2. **电磁保护**
   - 失超传播时铜提供分流路径
   - 降低失超传播速度和热点温度

3. **机械支撑**
   - 承受部分电磁力
   - 保护脆性超导细丝（尤其是 Nb₃Sn）

### 细丝化

- **细丝直径**：NbTi 通常 20-100 μm；Nb₃Sn 通常 10-50 μm
- **细丝化目的**：
  - 减小交流损耗
  - 提高稳定性（减小不稳定区尺寸）
  - 改善失超传播特性
- **细丝扭绞**：减小电磁耦合，减小交流损耗

## 2.5 导体选型决策矩阵

| 考量因素 | NbTi | Nb₃Sn | HTS (REBCO) |
|----------|------|-------|-------------|
| 目标磁场 | ≤10T | 10-20T | >20T |
| 运行温度 | 4.2K | 4.2K | 4.2-77K |
| 绕制难度 | 低（先绕后冷） | 高（wind-and-react） | 中 |
| 应变容忍度 | 高 | 低 | 中（弯曲受限） |
| 交流损耗 | 可优化到很低 | 可接受 | 低（各向异性） |
| 成本/T | 最低 | 中等 | 最高 |
| 成熟度 | 非常成熟 | 成熟 | 发展中 |

## 2.6 临界电流密度经验公式

### NbTi — 常用拟合公式
```
Jc(B) = C · B^(-1/2) · (1 - B/Bc2)^n   (n ≈ 2-2.5)
```
其中 C 取决于导体规格和加工工艺。

### Nb₃Sn — 迭代模型（Iterative Model）
```
Jc(B, T, ε) = Jc0 · b^p · (1-b)^q · (1-t^m)^n · f(ε)
```
其中 b = B/Bc2, t = T/Tc, f(ε) 为应变函数。

### Kramer 外推法
```
Jc^(1/2) · B^(1/4) vs B → 线性外推到 Jc = 0 得 Bc2*
```

> **重要提示**（南和礼）：临界电流数据应取自制造商提供的实测曲线，而非单纯依赖公式拟合。不同厂家、不同批次的导体 Jc 可能差异 20% 以上。
