# 3. 电磁设计

> 来源：南和礼《超导磁体设计基础》第5-6章；王秋良《高磁场超导磁体科学》第4-5章

## 3.1 螺线管磁场计算基础

### 单个圆电流环
轴上任一点磁场：
```
Bz(z) = μ₀·I·a² / [2·(a² + z²)^(3/2)]
```
其中 a 为环半径，z 为轴向距离，I 为电流。

### 有限长螺线管（薄壁近似）
轴上磁场分布：
```
Bz(z) = (μ₀·N·I / 2L) · [cosα₁ - cosα₂]
```
其中：
- L 为线圈长度
- N 为总匝数
- α₁, α₂ 为观察点到线圈两端的半张角

### 中心磁场
```
B₀ = (μ₀·N·I / 2L) · [L/√(a² + (L/2)²)]
     = μ₀·J·a · ln[(L/2 + √(a²+(L/2)²)) / (-L/2 + √(a²+(L/2)²))]  (厚壁)
```

### Fabry 公式（厚壁螺线管中心场）
```
B₀ = μ₀·J·a₁ · (α-1) · ln[(β + √(1+β²)) / (β + √(α²+β²))]
```
其中：
- a₁ 为内半径
- α = a₂/a₁（外径/内径比）
- β = L/(2a₁)（长径比）
- J 为工程电流密度

## 3.2 电感计算

### 单线圈自感
薄螺线管近似：
```
L ≈ μ₀·N²·π·a² / L_coil
```

更精确的 Brooks 公式考虑了线圈的有限截面。

### 多线圈系统
```
L_total = Σ L_self + Σ M_ij
```
互感 M_ij 通过 Neumann 公式计算：
```
M_ij = μ₀/(4π) · ∮∮ (dl_i · dl_j) / r_ij
```

### 储能
```
E = ½ · L · I²
```
这是失超保护能量分析的基础。

## 3.3 磁场均匀性设计

### 匀场设计目标
- MRI 应用：ΔB/B₀ < 10⁻⁴ ~ 10⁻⁶
- 一般科学实验：ΔB/B₀ < 10⁻³ ~ 10⁻⁴

### 匀场方法

**1. 几何优化（Southwell 方法）**
通过调整线圈的几何参数（半径、长度、位置）来抵消低阶球谐项。

**2. 补偿线圈**
在主螺线管内外添加补偿线圈，产生相反的场偏差以抵消不均匀性。

**3. 铁磁屏蔽**
在外围放置高导磁材料，改善远场分布。

### 球谐展开
磁场不均匀性可用球谐函数展开：
```
Bz(r,θ) = B₀ · Σ B_n · (r/R₀)^n · P_n(cosθ)
```
其中 P_n 为勒让德多项量。

- n=2：二阶不均匀性（主要影响项）
- n=4：四阶不均匀性
- n=6：六阶不均匀性

## 3.4 电流分布优化

### 优化问题
在给定导体总量和空间约束下，寻找电流分布 J(r,z) 使得：
1. 目标区域磁场均匀性最优
2. 或者在均匀性约束下最大化中心磁场

### 常用方法
- **线性规划法**：将线圈离散为电流元，用 LP 优化各元电流
- **非线性优化**：考虑导体临界特性（Jc(B) 非线性）
- **遗传算法**：适用于多目标优化

### 最小体积优化（南和礼重点）
在给定中心磁场和均匀性要求下，寻找导体用量最小的线圈构型：
```
Minimize: V_conductor
Subject to: B_center ≥ B_target
            ΔB/B₀ ≤ ε_target
            J ≤ Jc(B_local)
```

## 3.5 多线圈系统设计

### 背景场线圈 + 插入线圈
高场磁体通常由外层的低场 NbTi 背景线圈和内层高场 Nb₃Sn 插入线圈组成。

**设计步骤**：
1. 确定目标磁场和均匀性要求
2. 选择外层背景线圈（NbTi，承担大部分安匝数）
3. 设计内层插入线圈（Nb₃Sn，承担高场部分）
4. 优化两个线圈的几何匹配
5. 验算各位置的 J/Jc 裕度

### 磁体分级（Grading）
在不同磁场区域使用不同规格的导体：
- 高场区：高 Jc、小截面导体
- 低场区：较低 Jc、大截面导体
- 目的：最小化总导体用量和成本

## 3.6 交流损耗

### 损耗来源
1. **磁滞损耗**：超导细丝内的磁通运动
2. **耦合损耗**：细丝间通过基体金属的耦合电流
3. **涡流损耗**：基体金属和结构件中的涡流

### 减小交流损耗的方法
- 细丝化（减小直径）
- 扭绞（减小耦合长度）
- 采用高电阻率基体（如 CuNi 替代纯 Cu）
- 采用无磁支撑材料

### 估算公式
磁滞损耗（每周期每体积）：
```
Q_h ≈ (2/3) · μ₀ · Jc · a_f · ΔB
```
其中 a_f 为细丝半径，ΔB 为磁场变化幅度。
