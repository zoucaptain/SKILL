# 7. 高场磁体设计

> 来源：王秋良《高磁场超导磁体科学》重点章节；南和礼《超导磁体设计基础》相关章节

## 7.1 高场磁体的挑战

### 磁场强度限制
| 导体 | 实用磁场上限 (4.2K) | 主要限制因素 |
|------|---------------------|-------------|
| NbTi | ~10 T | Bc2 ≈ 15T, Jc 在 10T 以上急剧下降 |
| Nb₃Sn | ~20 T | Bc2 ≈ 30T, 但不可逆线远低于 Bc2 |
| Nb₃Al | ~22 T | 类似 Nb₃Sn，加工工艺更复杂 |
| Bi-2212 | ~30 T | 各向异性，线材加工困难 |
| REBCO | ~40 T+ | 成本极高，各向异性显著 |

### 关键挑战
1. **导体 Jc 在高场下急剧下降**
2. **电磁力随 B² 增长** → 结构应力成为极限
3. **储能密度随 B² 增长** → 失超保护难度增加
4. **Nb₃Sn 应变敏感性** → 高预紧与 Jc 退化之间的权衡
5. **磁场不均匀性控制** → 高场下更困难

## 7.2 混合磁体（Hybrid Magnet）

### 概念
将超导磁体（提供背景场）与电阻磁体（提供内层高场）结合，突破单一超导磁体的场强限制。

### 典型配置
```
外层：NbTi 背景线圈 → 产生 10-12T
中层：Nb₃Sn 插入线圈 → 产生 12-18T
内层：电阻磁体（水铜/铍铜） → 产生 18-45T
```

### 设计要点
- 电阻磁体需要极大的功率（MW 级）和强水冷
- 超导部分需承受电阻磁体产生的杂散场
- 接口设计：热隔离 + 力学匹配

## 7.3 高场 Nb₃Sn 磁体设计特殊考虑

### Wind-and-React 工艺约束
1. 线圈绕制在室温下完成（此时导体为 Nb+Cu 或 Nb+青铜）
2. 整体进行热处理（650-700°C）形成 Nb₃Sn
3. 反应后线圈变脆，不可再弯曲
4. 冷却至 4.2K 产生热应力

### 应变对 Jc 的影响
```
Jc(ε) / Jc(0) = 1 - a·|ε - ε_m|^b
```
其中 ε_m 为最优应变（通常 ~0.2-0.3% 压缩预应变）。

**关键后果**：
- 必须施加足够的压缩预应变使工作点接近 ε_m
- 但预压过大也会使应变偏离 ε_m
- 电磁力引起的附加应变必须考虑

### 设计裕度
高场 Nb₃Sn 磁体通常保留 15-25% 的电流裕度：
```
I_op = (0.75 - 0.85) · I_c(B_max, T, ε)
```

## 7.4 高温超导（HTS）磁体

### 材料
- **Bi-2212**（BSCCO-2212）：圆线/带材，各向异性较小
- **REBCO**（YBCO 等）：涂层导体（coated conductor），各向异性大
- **Bi-2223**（BSCCO-2223）：银套带材

### 优势
- Tc 高（80-110K）→ 可在更高温度运行
- Bc2 极高（>100T）→ 理论上无场强上限
- 低温下 Jc 保持良好至极高磁场

### 挑战
- **成本**：REBCO 导体成本是 NbTi 的 100 倍以上
- **各向异性**：Jc 对磁场方向敏感
- **连接技术**：HTS 导体接头电阻大
- **失超保护**：传播速度极慢（cm/s 量级）→ 需要不同的保护策略
- **机械性能**：REBCO 带材弯曲半径受限

## 7.5 高场磁体设计流程（王秋良方法论）

```
1. 确定目标磁场 B0 和均匀性要求
2. 选择导体体系（NbTi/Nb₃Sn/HTS/混合）
3. 初步电磁设计（计算安匝数、线圈尺寸）
4. 磁场分布计算（各位置的 B 值）
5. 导体分级设计（按局部 B 值选择导体规格）
6. 应力分析（电磁力 + 热应力 + 预紧）
7. 失超保护设计
8. 低温系统设计
9. 优化迭代（4-8 步循环）
10. 最终设计验证
```
