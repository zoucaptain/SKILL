# 1. 超导基础物理

> 来源：南和礼《超导磁体设计基础》第1-2章；王秋良《高磁场超导磁体科学》第1章

## 1.1 超导现象

**发现**：1911年，昂内斯（Onnes）发现汞在 4.2K 时电阻突降至零。

**两个基本特征**：
1. **零电阻效应** — 低于临界温度 Tc 时直流电阻严格为零
2. **迈斯纳效应**（Meissner effect） — 超导体内部磁感应强度 B = 0（完全抗磁性），区别于理想导体的"冻结磁通"

**热力学意义**：超导态是热力学平衡态（二级相变），不是单纯的动力学零电阻态。

## 1.2 临界参数

超导态由三个临界参数界定：

| 参数 | 符号 | 单位 | 物理意义 |
|------|------|------|----------|
| 临界温度 | Tc | K | 低于此温度才出现超导 |
| 临界磁场 | Hc (或 Bc) | T/A·m⁻¹ | 超过此磁场超导态被破坏 |
| 临界电流密度 | Jc | A/m² (或 A/cm²) | 超过此电流密度超导态被破坏 |

三者构成**临界曲面**：`Jc = f(B, T, ε)`，其中 ε 为应变。

### 临界磁场温度依赖
```
Bc(T) = Bc0 [1 - (T/Tc)²]
```
对于第二类超导体，有下临界场 Hc1 和上临界场 Hc2。

## 1.3 第一类与第二类超导体

| 特性 | 第一类 | 第二类 |
|------|--------|--------|
| 临界场 | 单一 Hc | Hc1 和 Hc2 |
| 磁化行为 | 完全迈斯纳态 → 直接跳变到正常态 | 迈斯纳态 → 混合态（涡旋态） → 正常态 |
| 典型材料 | 纯金属（Pb, Sn, Al, Hg） | 合金和化合物（NbTi, Nb₃Sn, YBCO） |
| 磁体应用 | 不适用 | 适用（可承载大电流同时承受高磁场） |

**第二类超导体用于磁体的根本原因**：在 Hc1 < H < Hc2 的混合态中，磁通以量子化涡旋线（fluxoid）形式穿透，但超导电流在涡旋之间流动，因此材料仍然具有超导性和载流能力。

## 1.4 磁通钉扎与临界电流

**关键概念**：第二类超导体中，涡旋线在洛伦兹力 `F = J × Φ₀` 作用下运动，产生电阻（磁通流动电阻）。

**磁通钉扎（Flux Pinning）**：材料中的缺陷（位错、析出相、晶界）将涡旋"钉住"，阻止其运动，从而维持零电阻状态。

**临界电流密度 Jc 的物理本质**：
```
Jc 对应于使洛伦兹力刚好克服钉扎力时的电流密度
即：Jc × Φ₀ = Fp (钉扎力密度)
```

**不可逆线（Irreversibility Line）**：在 B-T 平面上，Jc 降至工程实用阈值以下的边界。对于 Nb₃Sn，不可逆线远低于 Bc2(T)，这是高场应用的主要限制。

## 1.5 BCS 理论概要

BCS 理论（Bardeen-Cooper-Schrieffer, 1957）解释了常规超导的微观机制：

- **库珀对**（Cooper pairs）：电子通过声子媒介形成自旋反平行的配对
- **能隙**（Energy gap, Δ）：超导态与正常态之间的能量差，Δ(0) ≈ 1.76 kB Tc
- **相干长度** ξ：库珀对的空间尺度（NbTi ≈ 5nm, Nb₃Sn ≈ 3nm）
- **穿透深度** λ：磁场衰减的特征长度

对于磁体工程，最重要的宏观推论：
- Tc 越高 → 可在更高温度下工作
- Bc2 越高 → 可承受更高磁场
- ξ 越短 → 对缺陷更敏感（Nb₃Sn 的 ξ 短，需关注应变和微观结构）

## 1.6 实用超导材料比较

| 材料 | Tc (K) | Bc2(4.2K, T) | 最高实用场 (T) | 加工性 | 成本 |
|------|--------|---------------|----------------|--------|------|
| NbTi | ~9.2 | ~15 | ~10 | 优良（延展性好） | 低 |
| Nb₃Sn | ~18.2 | ~30 | ~20 | 差（脆性） | 中 |
| Nb₃Al | ~18 | ~30 | ~20+ | 中等 | 高 |
| Bi-2212 | ~85 | >100 | 30+ | 中等（BSCCO线材） | 高 |
| REBCO | ~90 | >100 | 40+ | 好（涂层导体） | 很高 |

> **选型原则**（南和礼）：10T 以下首选 NbTi（性价比最优）；10-20T 用 Nb₃Sn；20T 以上考虑高温超导或混合磁体方案。
