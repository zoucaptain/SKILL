# 8. 磁场分析与均匀性优化

> 来源：南和礼《超导磁体设计基础》第5-6章；王秋良《高磁场超导磁体科学》第4-5章

## 8.1 磁场均匀性指标

### 定义
磁场均匀性通常用目标区域内磁场偏差与中心场的比值表示：
```
均匀性 = ΔB / B₀ = (B_max - B_min) / B₀
```

### 应用要求
| 应用 | 目标区域 | 均匀性要求 |
|------|----------|------------|
| MRI（医学成像） | 40-60cm DSV | < 10⁻⁴ ~ 10⁻⁶ |
| NMR（核磁共振） | 几cm DSV | < 10⁻⁷ ~ 10⁻⁹ |
| 科学实验（一般） | 几cm-几十cm | < 10⁻³ ~ 10⁻⁴ |
| 粒子加速器 | 小孔径 | < 10⁻³（积分场） |
| 聚变装置 | 大体积 | < 1%（平均场） |

## 8.2 球谐分析

### 原理
轴对称磁场在目标区域内可展开为球谐级数：
```
Bz(r, θ) = B₀ · Σ_{n=0}^{∞} b_n · (r/R₀)^n · P_n(cos θ)
```
其中：
- B₀ 为中心磁场
- R₀ 为参考半径
- P_n 为勒让德多项式
- b_n 为各阶归一化系数

### 各阶不均匀性
| 阶数 n | 名称 | 场形特征 | 影响 |
|--------|------|----------|------|
| 0 | 均匀场 | 常数 | 有用场 |
| 1 | 梯度 | 线性变化 | 成像用梯度（MRI）/ 干扰 |
| 2 | 二阶（Z2） | 抛物线 | 主要不均匀性来源 |
| 3 | 三阶（Z3） | 反对称 | 端部不对称引起 |
| 4 | 四阶（Z4） | 四阶抛物线 | 次要不均匀性 |
| 5 | 五阶（Z5） | - | - |
| 6 | 六阶（Z6） | - | 高均匀性需考虑 |

### 对称性简化
对于关于中心对称的线圈结构，所有奇数阶项（n=1,3,5,...）自动为零。因此设计时主要关注偶数阶项（n=2,4,6,...）。

## 8.3 匀场方法

### 方法一：几何匀场（线圈形状优化）

**Southwell 方法**：通过调整线圈的几何参数来消除低阶不均匀性。

对于多线圈系统，可解方程：
```
Σ b_n_i (geometry_i) = 0  （对每个需要消除的阶 n）
```

**典型做法**：
- 调整各段线圈的长度和位置
- 添加补偿线圈（ shim coils）
- 优化主螺线管的长径比 β

### 方法二：电流匀场

在不同线圈段中分配不同电流，产生相反的场偏差：
```
目标：Σ I_i · b_n_i = 0
```

### 方法三：铁磁匀场（被动匀场）

在磁体内部或周围放置铁磁片（iron shim），利用其磁化产生的附加场修正不均匀性。

**优点**：可微调
**缺点**：引入非线性、温度依赖性、磁滞

## 8.4 屏蔽设计

### 主动屏蔽（Active Shielding）
在外层额外绕制反向电流线圈，抵消主磁体产生的杂散场。

**设计方程**：
```
B_stray(r_shield) = B_main(r_shield) + B_shield(r_shield) ≈ 0
```

**应用**：MRI 磁体（5 高斯线限制）

### 被动屏蔽（Passive Shielding）
用铁磁材料（钢壳）包围磁体，将杂散场限制在壳内。

**设计考虑**：
- 铁壳饱和磁场 ≈ 2T
- 壳厚度需确保不饱和
- 重量和成本

## 8.5 磁场计算方法

### 解析法
- 适用于简单几何（圆环、螺线管）
- 使用椭圆积分
- 快速、精确

### 数值法（Biot-Savart 积分）
```
B(r) = μ₀/(4π) · ∫ (J(r') × (r-r')) / |r-r'|³ dV'
```
- 将线圈离散为电流元
- 适用于任意电流分布
- 计算量大但通用

### 有限元法（FEM）
- 考虑材料非线性（铁磁材料）
- 处理复杂几何
- 软件：ANSYS Maxwell, Opera, COMSOL

### 设计精度要求
- 理论计算：±0.1%
- 制造公差影响：±0.5%
- 最终需通过实测（NMR 场图测量）验证

## 8.6 设计实例：匀场螺线管

### 目标
- B₀ = 3T
- DSV（均匀区直径）= 300mm
- 均匀性 < 5×10⁻⁵

### 设计步骤
1. 选择主螺线管：α=2.0, β=1.5（长径比）
2. 计算二阶系数 b₂，不为零
3. 添加一对补偿线圈（Helmholtz 配置）
4. 调整补偿线圈位置和电流，使 b₂ = 0
5. 检查 b₄、b₆ 是否满足要求
6. 若不满足，添加第二对补偿线圈
7. 最终验算整个 DSV 内的场分布

## 8.7 杂散场评估

### 5 高斯线
对于 MRI 和周边设备安全，需要评估 5 高斯（0.5 mT）线的范围。

**估算方法**：
在远场，磁体等效为磁偶极子：
```
B(r) ≈ μ₀ · m / (4π · r³)
```
其中 m = N·I·π·a² 为磁矩。

由此可估算 5 高斯线的距离：
```
r_5G ≈ [μ₀ · m / (4π · 5×10⁻⁴)]^(1/3)
```
