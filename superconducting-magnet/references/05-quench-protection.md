# 5. 失超保护

> 来源：南和礼《超导磁体设计基础》第9-10章；王秋良《高磁场超导磁体科学》第7章

## 5.1 失超机理

**失超（Quench）**：超导磁体局部区域从超导态转变为正常态的过程。

### 失超触发因素
1. **热扰动**：导体摩擦、微运动、辐射热、交流损耗
2. **电磁扰动**：磁通跳跃（flux jump）、电流引线扰动
3. **机械扰动**：线圈微位移（wire motion）、应力释放
4. **核辐射加热**（加速器等环境）

### 失超传播
一旦局部失超，正常区以有限速度向外传播：

**纵向传播速度（沿导线方向）**：
```
v_long ≈ √(κ · J²ρ / (C · ΔT))
```
其中 κ 为热导率，ρ 为正常态电阻率，C 为比热。

**横向传播速度（跨导线/跨层）**：
通常比纵向慢 1-2 个数量级。

### 最小失超传播能（MQE）
引发不可逆失超所需的最小能量输入：
```
MQE ∝ C · (T_c - T_op) · √(κ / ρ)
```
- MQE 越大 → 磁体越稳定
- 低温下比热 C 很小 → MQE 也很小（mJ 量级）

## 5.2 热点温度

### Joule 积分（Action Integral）
失超后热点温度的上升由 Joule 积分决定：
```
∫₀^tmax J(t)² · ρ(T) dt = ∫_T0^Tmax C(T) / ρ(T) dT
```

**物理含义**：焦耳热积累 = 材料从初始温度 T₀ 升至 T_max 所需的热量。

### 热点温度判据
| 温度上限 | 依据 |
|----------|------|
| 150K | 保守设计，保护绝缘和结构 |
| 300K | 常见上限，保护大多数材料 |
| 400-500K | 极限设计，需特殊绝缘材料 |

### 简化估算
对于铜基复合导体，假设绝热条件：
```
T_max ≈ T₀ + (I² · R_n · τ) / (m · C_avg)
```
其中 τ 为失超检测 + 泄放时间常数。

## 5.3 失超保护方法

### 1. 被动保护（自保护）
- **高铜比**：大截面铜基体提供分流和散热
- **分段绝缘**：增加横向热传播，加速失超传播
- **金属基体并联**：每个线圈段并联电阻

### 2. 主动保护

**a. 外部泄放电阻（Dump Resistor）**
```
检测到失超 → 闭合开关 → 储能泄放到外部电阻
电流衰减：I(t) = I₀ · exp(-t/τ), τ = L/R_dump
```
- R_dump 越大 → 衰减越快 → 热点温度越低
- 但 R_dump 过大 → 过电压风险

**b. 加热器驱动失超（Quench Heaters）**
```
检测到局部失超 → 触发分布加热器 → 强制整个线圈快速失超
```
- 目的：增大耗散面积，降低局部热点温度
- 响应时间：通常 10-100 ms

**c. 耦合损耗诱导（CLIQ）**
通过向线圈注入交变电流，在导体中产生耦合损耗，诱导均匀失超。

### 3. 保护电路参数选择

**泄放电阻优化**：
```
R_opt = √(L · (T_max_limit - T₀) · ρ_avg / (V_max · C_avg))
```
考虑因素：
- 最大允许电压 V_max（匝间绝缘和端子对地绝缘）
- 最大热点温度限制
- 系统电感 L

## 5.4 失超检测

### 检测方法
1. **电压检测法**：监测线圈段电压降，超过阈值触发保护
   - 灵敏度：通常 100-500 mV
   - 挑战：区分正常运行时的感应电压和真实失超电压

2. **温度检测法**：分布式温度传感器（二极管、RTD）
   - 响应较慢（热传导延迟）

3. **光纤检测**：FBG 光纤传感器监测温度和应变

### 检测延迟
从失超起始到触发保护的时间通常为 10-100 ms。这段时间内热点温度已开始上升。

## 5.5 失超保护设计流程

```
1. 计算磁体总储能 E = ½LI²
2. 确定可接受的热点温度 T_max（通常 150-300K）
3. 计算最小泄放时间常数 τ_min
4. 选择泄放电阻 R_dump = L/τ_min
5. 验算最大电压 V_max = I₀ · R_dump（是否超过绝缘耐压）
6. 设计失超检测方案（阈值、延迟）
7. 评估是否需辅助加热器
8. 进行失超模拟验证（热点温度、电压、电流衰减曲线）
```

## 5.6 失超模拟要点

数值模拟需考虑：
- 电流-热-电磁耦合
- 材料参数随温度的变化（ρ(T), C(T), κ(T)）
- 线圈各部分的传热路径
- 保护电路的动态响应
- 最坏情况场景（最大电流、最慢检测）
