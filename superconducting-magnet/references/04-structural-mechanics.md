# 4. 结构力学与支撑设计

> 来源：南和礼《超导磁体设计基础》第7-8章；王秋良《高磁场超导磁体科学》第6章

## 4.1 电磁力分析

### 洛伦兹力密度
```
f = J × B
```
单位体积上的电磁力等于电流密度与磁感应强度的叉积。

### 力的分量
在轴对称螺线管中：

**径向力（向外）**：
```
fr = Jθ · Bz
```
导体中电流产生向外的膨胀力，类似"爆胀"效应。

**轴向力（向内压缩）**：
```
fz = -Jθ · Br
```
轴向分量将线圈各段相互挤压。

### 总力的估算

**总径向力**：
```
Fr ≈ B₀² · π · a² / (2μ₀) · L/a  (近似)
```
对于大型高场磁体，径向总力可达数 MN 量级。

**总轴向力**：
线圈各段之间的吸引力，最大值出现在端面附近。

## 4.2 应力分析

### 环向应力（Hoop Stress）
薄壁圆筒近似：
```
σθ = p · a / t = (J · B · a)  (当 p = J·B·t)
```
其中 p 为等效径向压力，a 为半径，t 为壁厚。

**关键判据**：σθ 必须小于导体/结构的许用应力。

### 轴向应力
```
σz ≈ σθ / 2  (薄壁圆筒)
```
实际值取决于端部约束条件。

### 剪切应力
在各向异性复合材料（超导+铜）中，层间剪切是薄弱方向。

## 4.3 典型应力水平

| 磁体类型 | B₀ (T) | σθ_max (MPa) | 备注 |
|----------|--------|---------------|------|
| 低场 NbTi MRI | 1.5 | ~50 | 环氧树脂包封可承受 |
| 高场 NbTi 科学 | 10 | ~200 | 需加强支撑 |
| Nb₃Sn 插入线圈 | 18 | ~350 | 需预压 + 高强度外壳 |
| 混合磁体内层 | 25+ | ~500+ | 极端工程挑战 |

## 4.4 预紧力设计（Preload）

### 预紧目的
1. 抵消运行中的电磁膨胀力，保持线圈受压
2. 防止 Nb₃Sn 导体受拉（其抗压不抗拉）
3. 改善接触传热
4. 抑制失超传播中的机械扰动

### 预紧方法

**1. 热套法（Shrink Fit）**
```
外壳加热 → 套入线圈 → 冷却收缩 → 产生径向压力
```
预紧力：`p = E_shell · δ / a`（δ 为过盈量）

**2. 机械预紧**
- 使用拉杆、螺栓施加轴向预压
- 楔块结构施加径向预压

**3. 带材缠绕预紧**
用高强度带材（不锈钢/玻璃纤维）以张力缠绕线圈。

### 预紧力计算要点
```
运行时的净应力 = 预紧压应力 - 电磁拉应力
```
设计准则：运行时环向净应力 ≥ 0（全截面受压），或至少 σ < σ_allow。

## 4.5 结构支撑系统

### 磁体外壳
- **功能**：承受径向膨胀力 + 提供预紧 + 约束轴向位移
- **材料**：高强度不锈钢（如 316LN）、Inconel、铝合金
- **厚度设计**：按薄壁/厚壁圆筒理论 + 安全系数

### 端部支撑
- **功能**：承受轴向压缩力，防止线圈端部鼓出
- **形式**：端法兰 + 拉杆、锥形楔块
- **难点**：端部场不均匀 → 径向力分量 → 额外剪切

### 低温收缩兼容性
所有结构材料必须考虑从室温到 4.2K 的热收缩差异：

| 材料 | 收缩率 (300K→4.2K) |
|------|-------------------|
| 不锈钢 316LN | ~0.3% |
| 铝合金 6061 | ~0.4% |
| 铜 | ~0.35% |
| 环氧树脂 | ~0.5-1% |
| NbTi 复合导体 | ~0.3% |

设计时需确保低温下不产生过大残余应力或松动。

## 4.6 失效力分析（Quench-induced Forces）

失超发生时：
1. 电流快速衰减 → 产生 dB/dt
2. dB/dt 在导体中感应涡流
3. 涡流 × 磁场 → 附加瞬态力
4. 瞬态力可能超过稳态电磁力，是结构设计的极限工况

## 4.7 设计检查清单

- [ ] 计算所有线圈段的 J × B 分布
- [ ] 验证最大环向应力 < 材料许用应力（含安全系数 1.5+）
- [ ] 设计预紧系统，确保运行时不出现拉应力（Nb₃Sn 必须）
- [ ] 校核端部支撑强度和稳定性
- [ ] 计算低温收缩后的预紧力变化
- [ ] 评估失超瞬态力峰值
- [ ] 检查所有焊缝和连接处的应力集中
