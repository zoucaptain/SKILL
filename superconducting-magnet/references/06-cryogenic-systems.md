## 6.2 低温传热机制

### 传导传热
```
q = -κ · dT/dx
```
低温下材料热导率 κ 随温度变化显著：
- 纯金属（铜、铝）：κ ∝ T（低温下很高）
- 合金和不锈钢：κ 较低
- 绝缘材料（环氧树脂、G10）：κ 极低（设计隔热层的关键）

### 对流传热
液氦自然对流和强制对流。

**池沸腾传热（Pool Boiling）**：
1. 自然对流区（小 ΔT）
2. 核态沸腾区（中等 ΔT）— 传热系数最高
3. 膜态沸腾区（大 ΔT）— 传热急剧恶化（偏离核态沸腾，DNB）

**DNB 热流密度**（关键设计参数）：
```
q_DNB ≈ 0.1-1 W/cm² （取决于压力和几何条件）
```
导体表面热流密度必须远低于 DNB，否则会形成氦气膜，传热恶化导致失超。

### He II 传热（超流氦）
T < 2.17K（λ 点）时，氦进入超流态：
- 表观热导率极高（等效 κ > 10⁴ W/(m·K)）
- 传热由内部对流机制（counterflow）主导
- 存在临界热流密度 q*，超过后传热恶化

## 6.3 热负荷计算

### 热负荷组成

**1. 传导热负荷**
```
Q_cond = Σ (κ · A / L) · ΔT
```
通过支撑结构、电流引线、管路的传导。

**2. 辐射热负荷**
```
Q_rad = ε · σ · A · (T_warm⁴ - T_cold⁴)
```
通过多层隔热（MLI）可大幅降低。

**3. 交流损耗热负荷**
```
Q_AC = f · Σ Q_cycle
```
交流运行或磁场变化时的损耗。

**4. 电流引线热负荷**
```
Q_lead ≈ I · √(2 · κ · ρ · ΔT / L_opt)
```
最优引线设计使传导热和焦耳热之和最小。

**5. 支撑结构热负荷**
通过机械支撑从室温到低温的热传导。

### 典型热负荷数量级
| 热负荷源 | 典型值 |
|----------|--------|
| 辐射（有 MLI） | 0.1-1 W/m² |
| 传导支撑 | 0.5-5 W 每支撑 |
| 电流引线（一对） | 0.5-2 W/kA |
| 管路/电缆 | 可变 |

## 6.4 制冷循环

### 克劳德循环（Claude Cycle）
最常用的氦气制冷循环：
```
压缩机 → 预冷 → 膨胀机（等熵膨胀） → 换热器 → 节流阀 → 液氦
```

### 制冷功率
```
COP = Q_cold / W_input
```
卡诺极限（4.2K → 300K）：COP = 4.2/(300-4.2) ≈ 1.4%
实际氦制冷机 COP ≈ 0.1-0.3%（远低于卡诺极限）

**工程估算**：每移除 1W @ 4.2K 需要约 700-1000W 的输入功率。

### 制冷机类型
| 类型 | 制冷量 @ 4.2K | 适用场景 |
|------|---------------|----------|
| GM 制冷机 | <2 W | 小型系统、预冷 |
| 脉冲管制冷机 | 1-10 W | 无振动要求 |
| 大型氦制冷机 | 100W-数kW | 大型加速器、聚变装置 |
| 透平膨胀机 | 数十W-数百W | 中等规模系统 |

## 6.5 低温恒温器（Cryostat）设计

### 基本结构
```
┌─────────────────────────────────────┐ ← 室温外壳 (300K)
│  ┌───────────────────────────────┐  │
│  │  热辐射屏蔽 (80K / 液氮冷却)   │  │ ← 中间温度屏蔽
│  │  ┌─────────────────────────┐  │  │
│  │  │  超导电圈 (4.2K)         │  │  │ ← 低温区
│  │  │  浸泡在液氦中            │  │  │
│  │  └─────────────────────────┘  │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

### 多层隔热（MLI）
- 交替放置反射箔（铝化聚酯薄膜）和间隔材料
- 典型：20-40 层
- 可将辐射热降至 <0.5 W/m²

### 设计考虑
- 最小化热传导路径（细长支撑、低 κ 材料）
- 优化辐射屏蔽温度
- 确保足够的液氦容量和保持时间
- 考虑失超时的气体排放（安全阀）

## 6.6 电流引线（Current Leads）

### 最优设计
从室温电源到低温线圈的电流引线是主要热源之一。

**最优截面积**：
```
(A/L)_opt = I · √(ρ_avg / (2 · κ_avg · ΔT))
```
最优设计下，每对引线的热负荷：
```
Q_opt ≈ I · √(2 · κ_avg · ρ_avg · ΔT)
```

### 材料选择
- 铜：高电导、高热导 → 需平衡
- 黄铜/铜合金：降低热导、增大电阻 → 适合小电流
- HTS 电流引线：利用高温超导段减少传导热
