# Chapter 3: 纯金属电阻率

## 3.1 本征电阻率

### 定义

本征电阻率 = 纯完美金属的电阻率，来源于电子被晶格振动（声子）散射。

### Bloch-Grüneisen 公式

```
ρi = C·(T/θ)⁵ · ∫₀^(θ/T) z⁵/[(eᶻ-1)(1-e⁻ᶻ)] dz
```

- θ：特征温度（德拜温度）
- K：常数

### 常用金属的 θ 值

| 金属 | θ (K) |
|------|-------|
| 铜 | 330 |
| 铝 | 395~400 |
| 铍 | 1200 |
| 钠 | 200 |

### 温度依赖性

- **T > θ/2**：ρi ∝ T（线性）
- **T < θ/10**：ρi ∝ T⁵

### 实际结论

1. 大多数金属在室温附近显示 ρ 对 T 的线性依赖关系
2. 高温时经常偏离线性
3. **低于约 20K，大多数金属没有可靠的电阻率表达式**
4. 高于约 20K，Bloch-Grüneisen 公式通常提供良好估算

### 低温本征电阻率示例

- 铜 (4K)：~3.5 × 10⁻⁵ μΩ·cm（RRR = 4.4 × 10⁴）
- 铝 (4K)：~6 × 10⁻⁴ μΩ·cm（RRR = 4.0 × 10³）

这些值远高于实验测得的最佳电阻率比。

## 3.3 晶体学转变

- 少数纯金属在室温以下有晶体学转变
- 锂：冷却到 ~77K 时转变为六方
- 钠：~36K
- 锡：286K 以上为四方，可能以下为金刚石结构
- 铈：~265K 到 90K 间经历复杂的 FCC→HCP→FCC 转变系列
- 锰的各相电阻率相差近 **7 倍**

## 3.4 磁性转变

- 低温磁性转变（顺磁→反铁磁→铁磁）主要出现在稀土元素中
- 常见金属中：α-Mn (70-90K)、Cr (~310K) 显示反铁磁转变
- 纯软铁磁材料（如铁）在极低电流值下，低温电阻率强烈依赖于测量电流

## 3.5 杂质的影响

### 核心规则

1. **固溶态杂质元素总是使电阻率增加**
2. **增加量与浓度呈线性关系**（只要杂质保持固溶态）
3. **溶质元素的贡献是可加的** → 可从好的化学分析计算低温电阻率
4. 室温测量的杂质电阻贡献与 4K 的值相差约 5% 以内（低温值通常更高）

### Matthiessen 法则及其偏离

Matthiessen 法则：ρ(c,T) = ρp(T) + ρi(c)

实际上存在偏离项 Δ(c,T)：
```
ρ(c,T) = ρp(T) + ρi(c) + Δ(c,T)
```

**偏离行为特点：**
- 低温时，Δ 随温度上升，通常慢于 ρp(T)，但常在 θ/10 附近超过 ρp(T)
- 在 θD/3 到 θD/4 处可能出现驼峰
- 高温时，Δ 通常是 ρ₀ 的 5-10%

## 3.6 Kondo 效应

- **现象**：含有稀磁溶质的纯金属和合金中，电阻率出现最小值
- **典型温度范围**：2-30K
- **经典材料**：CuFe
- **物理机制**：局域杂质磁矩与附近传导电子平均磁矩之间的相互作用
- 在几乎所有"纯"铜中可见（指示其铁含量较高）
- 铜中铁杂质的内氧化可完全消除 Kondo 最小值

## 3.7 气体作为杂质

- **氧**：最常见，"无氧"铜中也含 10-20 ppm
  - 铜中氧的电阻贡献：5.3 μΩ·cm/at.%
- **氮**：用于现代不锈钢中作为强化元素
- **氢**：导致严重脆化问题
- 稀有气体合金：低杂质水平下贡献正常，~40 at.% 时 7K 电阻率仅 ~100 μΩ·cm

## 3.8 尺寸效应

- 当样品尺寸接近或小于电子平均自由程时，测量的 RRR 低于体材料 RRR
- **纯金属线材**：即使合理尺寸也会显示显著的尺寸效应
- 施加磁场到显示显著尺寸效应的金属，可能导致测量的低温电阻率**急剧下降**
