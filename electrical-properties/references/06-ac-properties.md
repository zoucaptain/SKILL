# Chapter 6: 交流电阻率与介电材料

## 6.1 趋肤效应 — 经典与反常

### 经典趋肤深度

```
δ = (2ρ/ωμ)^(1/2)
```

- ω：施加的角频率
- μ：磁导率 (H/m)
- ρ：电阻率 (Ω·m)
- δ：趋肤深度 (m)

场能量基本为磁性，波在金属内指数衰减，在距离 δ 处降到表面值的 37%。

### 关键影响

- 高频下（如 ~100MHz，室温铜 δ ≈ 0.007mm），电流几乎"仅在表面流动"
- AC 电阻 = R_dc × (r/2δ)（当 r >> δ 时）

### 1Hz 时的趋肤深度 (RRR=1000)

| 材料 | 温度 (K) | 趋肤深度 (mm) |
|------|---------|-------------|
| 铜 | 293 | 66 |
| 铜 | 4 | 2.1 |
| 铝 | 293 | 82 |
| 铝 | 4 | 2.6 |
| 铁 (μ=100) | 293 | 16 |
| 铁 (μ=100) | 4 | 0.5 |
| 铁 (μ=1000) | 293 | 5.0 |
| 铁 (μ=1000) | 4 | 0.16 |

### 关键信息

> **在室温下基本表现为 DC 特性的导线（r < δ），在 4K 时可能表现出高得多的电阻（r >> δ）。**

### AC 电阻与导线半径/趋肤深度比

- r/δ < 1：AC 电阻 ≈ DC 电阻
- r/δ = 2：AC 电阻 ≈ 1.5 × DC 电阻
- r/δ = 4：AC 电阻 ≈ 2.5 × DC 电阻
- r/δ = 10：AC 电阻 ≈ 5 × DC 电阻
- r/δ > 10：AC 电阻 ∝ r/δ

### 反常趋肤效应

- 当趋肤深度接近或小于电子平均自由程时发生
- 唯一对电导有贡献的电子是那些在一个平均自由程时间内不离开趋肤深度层的电子
- 表面电阻变得与金属纯度**无关**，且显著大于经典趋肤效应预测值
- 示例：纯铝 (RRR=10000) 在 4K 时，低至 **~10Hz** 的频率就出现显著反常趋肤效应

## 6.2 涡流与磁扩散

### 磁扩散

```
D_mag = ρ/μ
```

- 4K 时纯金属的磁扩散率 ~1 cm²/s
- 合金的磁扩散率 ~数百 cm²/s
- 与热扩散率比较：判断涡流发热是否能通过传导迅速散去

### 涡流损耗

#### 薄板（厚度 a，平行均匀场中）

**情况 1：a >> δ（电感限制）**
```
P_ec = H_s²ωρ/δ
```
- 损耗 ∝ ω^(1/2)

**情况 2：a << δ（电阻限制）**
```
P_ec = H_s²ω²ρ·a³/(6δ²)
```
- 损耗 ∝ ω²

### 关键警告

> 在 4K 时，如果使用错误的公式（电阻限制公式代替电感限制公式），结果可能**大七个数量级**！

### 铁磁材料的 AC 损耗

- 磁导率 μ 不再独立于 H
- μ 也随温度变化
- 磁滞损耗经常超过涡流损耗
- 与畴壁运动等现象相关的损耗

## 6.3 介电材料

### 极性 vs 非极性

| 类型 | 材料 |
|------|------|
| 非极性 | 聚乙烯、聚丙烯、聚四氟乙烯 (TFE) |
| 极性 | 纸、聚对苯二甲酸乙二酯 (PET)、聚均苯四甲酰亚胺 (PPMI) |

### 关键性能

1. **击穿强度**（DC、AC、脉冲）
   - 聚合物倾向于数十 kV/mm 厚度
   - 受温度影响不大
   - 一些极性材料冷却到 4K 时增加 10-20%
   - 实际情况下，击穿通常在低得多的电场下发生（表面闪络或与低温介质相互作用）

2. **介电常数 (ε)**
   - 非极性材料：几乎不受温度影响
   - 极性材料：随温度变化显著

3. **损耗角正切 (tan δ)**
   - 4K 时极性材料典型值：10⁻³ 到 10⁻⁴
   - 非极性材料：<10⁻⁴
   - 通常随温度下降而减小
   - 大多数不规则行为在 4K 时已结束

### 介电损耗功率

```
P = ωCV·tan δ
```

### 重要现实

> 考虑到所有不确定性，加上大多数材料的大热收缩和快速脆化，低温下使用介电材料是一种"令人沮丧的练习"，目前**没有完全可接受的介电材料**。

### 未来方向

- 化学定制更有希望的聚合物
- 评估聚合物混合物和低损耗粉末填充聚合物
- 评估有前景的非聚合物材料
