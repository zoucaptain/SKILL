# Chapter 2: 实验技术与测量方法

## 2.1 基本电阻率公式

```
ρ = RA/ℓ = VA/(Iℓ)
```

- R：样品电阻
- V：测得电压
- I：电流
- A：样品截面积
- ℓ：电压探针间距

A 和 ℓ 通常可精确到 0.5%。

## 2.2 直流测量 (DC)

### 典型系统组成

1. **电流源**：汽车电池到精密电流校准器均可，需在测量时间内稳定
2. **标准电阻**：阻值足够低，避免最高电流时显著发热
3. **纳伏表 + 数字电压表**：提供良好精度 (~1%)，成本低
4. **四探针系统**（电流和电压独立引线）：**最佳方法**
   - 两引线系统引入太多误差源

### 关键操作

- **电流反向**：必须执行，以消除热电势
- 标准电阻功率耗散限值由制造商规定，通常比预期低

## 2.3 交流测量 (AC)

- 锁相放大器技术看似有优势（消除热电势），但精确测量 <1 Ω 电阻需要"非常规"技术
- AC 桥路电路已用于低温电阻温度计应用
- **屏蔽、接地和变压器正确使用**是主要问题

## 2.4 涡流衰减法

### 特点

- **速度极快**（1-5% 精度）
- **无需连接引线**到样品
- 可测量**奇形怪状样品**的电阻率比
- 设备相对昂贵，部分需自制

### 适用场景

- 退火恢复曲线
- 杂质偏析实验
- 需要重复低温测量的实验

### 系统组成

```
电流源 → 初级线圈 → 样品（液氮/液氦杜瓦中）
                    → 次级线圈 → 放大器 → 记录仪/示波器
```

## 2.5 低电平测量

当需要测量远低于微伏级的电压时：

- **商用纳伏表和电位计**仍很难实现 1% 精度
- **SQUID 检测器**（超导量子干涉器件）用于极低电平
- 其他方法：磁放大器、霍尔效应放大器、超导调制器、继电器调制器

## 2.6 温度控制

### 恒温浴法

使用液化气体和有机流体浆液（固液混合物）：

| 物质 | 温度 (K) | 浴类型 |
|------|----------|--------|
| 冰水 | 273.15 | 浆液 |
| 四氯化碳 | 250 | 浆液 |
| 丙烷 | 230.8 | 液体沸点 |
| 二氧化碳 | 194.6 | 固体 |
| 甲烷 | 111.7 | 液体沸点 |
| 氧气 | 90.1 | 液体沸点 |
| 氮气 | 77.3 | 液体沸点 |
| 氖 | 27.2 | 液体沸点 |
| 氢气 | 20.4 | 液体沸点 |
| 氦⁴ | 4.2 | 液体沸点 |
| 氦³ | 3.2 | 液体沸点 |

- 液体气体浴的温度取决于压力和海拔
  - 例如：液氦在 Boulder (1610m) 沸点 4.0K，海平面 4.2K
- 减压泵送可获得更低温度：~1K (氦)、14K (氢)、25K (氖)、64K (氮)

### 电加热器控温

- 电加热铜块（与样品良好热接触，通过适当热漏与冷浴隔离）
- 低温精度：~50 mK 容易获得；1 mK 需要小心
- 文献报道系统可达 50 μK 甚至 1 μK 控制精度

## 2.7 样品粘接

- 良好热粘接对样品和散热块很重要
- 粘接剂应为电绝缘体
- 常用电绝缘清漆和各种油脂
- 应检查样品-散热块温差（可用差动热电偶）

## 2.9 引线连接

### 压力接触

- 液体浴中通常足够
- 钢制刀口、黄铜螺钉、裸铜线均可
- 室温下弹簧加载效果良好
- **在强磁场中效果不佳**（电压信号噪声大）

### 焊接/点焊

- 磁场测量或温度范围测量时，焊接/点焊是唯一合理方法
- 焊料熔点：~373K (BiPbSn) 到 ~473K (PbSn)
- 几乎都超导，有些临界温度 >7K，临界场 ~1T
- 焊点面积大，降低探针间距测量精度

### 高精度探针安装技术

1. 样品涂清漆、固化
2. 钻 0.2mm 直径孔到金属表面
3. 插入 0.12mm 低熔点焊料球
4. 加热熔化焊料
5. 插入预镀锡电压引线

## 2.10 引线热考量

- 引线导热有时会造成问题
- 使用高热阻合金（康铜、Evanohm、锰铜）有高电阻代价
- **常见方案**：用铜线，但将合理长度引线锚定到散热块
- 所有 DC 电位测量应为**电流正反两次读数的平均值**

## 2.11 热收缩

- 纯金属刚性连接到塑料基板 → 冷却时金属受压 → 屈曲
- 解决方案：
  1. 允许样品在夹具中运动
  2. 整个夹具使用与样品相同类型的材料（如纯金属用铜夹具）
  3. 匹配夹具材料与样品的膨胀系数（填充环氧树脂或石墨-环氧复合材料）
