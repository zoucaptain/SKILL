# Chapter 5: 外部电阻机制

## 5.1 磁阻效应 (Magnetoresistance)

### 基本原理

- **所有非磁性金属**的电阻率随磁场增加而增加
- 低温下效应更强（因为本征/声子电阻分量很小）
- 对纯铜已有 60+ 篇论文（截至 1972 年）

### Kohler 法则

```
Δρ/ρ₀ = f(H/ρ₀)
```

- H：施加磁场
- ρ₀：零场电阻率
- 函数 f 对多晶金属是单值的、单调递增
- 仅取决于金属种类及场与电流的相对取向
- **不直接依赖于杂质含量或温度**（除通过影响 ρ₀ 外）

### Kohler 图

- log-log 图：Δρ/ρ vs H·RR(T)
- RR(T) = ρ(273K)/ρ(T)
- 铜与 Kohler 法则吻合度极高
- 数据覆盖：温度 4-20K，磁场到 9T，RRR 从 10 到 10000
- **极纯铜中，场致电阻增加可达 100 倍！**

### 铝的磁阻

- 不服从 Kohler 法则
- 电阻率上升后几乎饱和
- 给定磁场下，Δρ/ρ 在 ~20K 附近出现峰值
- 最大值 Δρ/ρ 为 0.5-5，远低于铜

### 一般规律

1. 几乎任何多晶金属在小纯度范围和固定温度下都与 Kohler 法则部分吻合
2. 很少金属在宽温度、纯度、缺陷浓度和场范围内吻合
3. **纵向磁阻总是低于横向**，通常低 2 倍以上
4. **纵向磁阻总是随场饱和**
5. 尺寸接近或小于电子平均自由程的样品，外加磁场可能使电阻**下降**
6. **铁磁金属和合金**常显示磁阻随场增加而**下降**

### 铁磁金属

- 合金：下降通常很小（如 Cu42at.%Ni：Δρ ~ -0.25 μΩ·cm，残余电阻 47 μΩ·cm）
- 纯铁磁金属：变化可能很大
  - 多晶铁（RRR=2500）：ρ 从 ~40 μΩ·cm 降到 ~3 μΩ·cm

### 关键信息

> **超过某一纯度值后，继续提高纯度没有意义，因为磁阻效应会补偿。**

## 5.2 霍尔效应 (Hall Effect)

### 定义

```
E_H = R_H · J · H
```

- E_H：霍尔电场
- R_H：霍尔系数
- J：电流密度
- H：施加磁场

### 特点

- 霍尔电压可正可负
- 通常非常小
- **R 随温度下降减少不多**
- 在 4K 纯金属样品上，霍尔电压分量可能远大于电阻电压
- 简单理论：R ∝ 1/传导电子数

### 典型值

| 材料 | R_H (m³/As) |
|------|------------|
| 铜（极纯） | ~5 × 10⁻¹¹ |
| 铟掺杂锗 | ~+10⁴ |

### 测量注意

- 必须同时反向 H 和 J
- 存在偶函数电压分量（横向偶和平面霍尔电压）

## 5.3 压力效应

### 流体静压力

- 31 种正常金属的电阻率随压力增加而**下降**（包括所有常用金属）
- 大多数金属在 ~10⁹ kg/m² 压力下变化 1-5%
- 低温时百分比变化更大
- 铜在 10⁹ kg/m² 时总下降 ~13%（vs. 1.9% 在 10⁸ kg/m²）
- 更高压力下 dp/dP 变小

### 第二类金属（碱金属、半金属、稀土）

- 行为范围宽，变化可能很大
- 铜的本征电阻率随压力下降的速率在 4K 时比室温高约 4 倍
- 残余电阻率随压力**增加**（温度到 80K），增加率随温度升高而减小

## 5.4 应力与疲劳

### 应力效应

- 施加恒定或交变应力几乎总是使电阻率**增加**
- 弹性范围内：应力移除后可逆（合金应变片的基础）
- 塑性区域：形成缺陷，不可逆变化

### 影响电阻增加的因素

| 因素 | 影响 |
|------|------|
| 温度 | 温度越低，给定变形的电阻增加越大 |
| 起始状态 | 预冷加工可能增加初始应变依赖性 |
| 合金元素 | 通常合金含量增加，应变敏感性增加 |
| 应力类型 | 拉伸、压缩、扭转效果不同 |

### 变形与温度关系（铜为例）

- 相同变形量下，低温（90K）的电阻增加大于室温（295K）
- 绘制 Δρ 与 ln(A₀/A) 的关系

### 退火恢复阶段

残余电阻在相当明确的温度范围内分五个阶段下降：

| 阶段 | 机制 |
|------|------|
| I | 附近空位和间隙原子的复合（辐照样品中常见） |
| II | 扩散空位和间隙原子的复合，迁移到位错 |
| III | 空位团簇及团簇迁移 |
| IV | 塑性变形样品中位错的退火 |
| V | 位错的退火 |

具体阶段是否明显取决于：
- 具体金属及其化学纯度
- 初始状态来源（辐照、轻微变形、大变形）
- 变形方法或辐照粒子类型

### 疲劳

- 即使在相对低应变值下，低温疲劳也可导致残余电阻率显著增加
- 电阻在前几个循环上升较快，然后较慢
- 纯铜疲劳（0.2% 恒定应变，数百循环）：
  - RRR=2200 起始材料：~2 μΩ·cm
  - RRR=223 起始材料：~11 μΩ·cm
- 电阻增加在整个应变范围（到 0.88%）和大量循环（到 10⁶）内呈**指数关系**
