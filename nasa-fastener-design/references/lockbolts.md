# 锁螺栓 — Lockbolts

来源: NASA Fastener Design Manual, "Lockbolts" (p.30-38)

## 概述

锁螺栓是一种**不膨胀的高强度紧固件**，通过**滚压套筒**或**螺纹套筒**锁紧。

### 通用特性
- 安装在标准钻孔中（ snug fit，通常非过盈）
- 类似铆钉：锁紧环/螺母抗拉弱，安装后难以拆卸
- 部分类型可**单侧完全安装**（类似盲铆钉）
- 部分从远侧送入，近侧用枪完成
- 有沉头和凸头可选
- 比标准螺栓+螺母**安装快得多**

### 使用原则
- 难以确定是否正确安装→**仅在无法安装同等强度螺栓+螺母时使用**
- 有沉头和凸头可选

---

## 1. Hi-Lok 锁螺栓

- 沉头或凸头制造头
- **螺栓式螺纹**
- 从远侧穿入孔
- 安装工具用六角键防止杆部旋转，同时安装螺母（套筒）
- 螺母六角端有切口→在**设定扭矩**处断裂

### 材料/强度
| 材料 | 最大剪切强度 (ksi) |
|------|-------------------|
| 高强度碳钢 | 156 |
| 不锈钢 | 132 |
| 钛合金 | 95 |

### 安装步骤
1. 从远侧穿入预钻孔
2. 近侧安装工具夹持六角键
3. 安装套筒（锁紧环）
4. 拧紧至六角端断裂

---

## 2. Huckbolt

- 类似Hi-Lok
- 杆部通常为** serrated（锯齿形）**而非螺纹
- 套筒**滚压**在杆上
- 杆部在切口处断裂

### 材料
- 碳钢、铝、不锈钢等多种强度可选

---

## 3. Taper-Lok

- **高强度螺纹紧固件**
- **干涉配合**安装
- 大部分杆部为 **1.19° 锥角**
- 润滑后装入**钻孔+铰孔**
- 干涉配合允许安装螺母（拉/剪）并拧紧到所需扭矩，**无需固定锁螺栓防旋转**

### 螺母类型
- 拉紧螺母 (tension nut)
- 剪切螺母 (shear nut)
- 锁紧螺母 + 整体垫圈

### 优势
- 安装拉紧螺母时，可承受**与同尺寸同材料螺栓相同的拉力**
- 用于**循环载荷**关键应用

### 材料
- 高强度合金钢
- H-11工具钢
- 多种不锈钢
- 钛合金

---

## 4. Jo-Bolt

- 外观和安装类似盲铆钉
- 锁紧套筒（套管）通过旋转螺纹芯轴膨胀形成镦头
- 螺纹芯轴有切口→达到设定扭矩时断裂
- 从单侧安装

---

## 5. Rivnut（铆螺母）

- 管状铆钉 + 内螺纹 = 现场变形的**盲螺母板**
- 头型：凸头、沉头、平头
- 变体：闭端、密封头、加强筋杆、六角杆
- 材料必须延性（管状部分需变形）→**强度较低**

### Rivnut材料表
| 材料 | 处理 | 最小极限抗拉强度 |
|------|------|----------------|
| 铝6053-T4 | 阳极氧化 | 205 psi |
| 钢C-1108 | 镉镀0.0002" | 45,000 psi |
| 钢4037 | 镉镀0.0002" | 65,000 psi |
| 不锈钢430 | 酸洗钝化 | 67,000 psi |
| 不锈钢305 | 机加工 | 80,000 psi |
| 黄铜260 | 机加工 | 50,000 psi |

---

## 6. Hi-Shear 铆钉

- 高强度碳钢/不锈钢/铝/钛销
- 镦粗镦头 + 套筒（2024铝或Monel）
- **仅用于剪切**（套筒抗拉可忽略）
- 套筒可**目视检查**成形是否正确
- 部分被各类锁螺栓取代

---

## 锁螺栓选型建议

| 需求 | 推荐 |
|------|------|
| 高强度剪切，可双侧 | Hi-Lok (最高156 ksi) |
| 高速安装 | Huckbolt |
| 循环载荷/拉力 | Taper-Lok |
| 单侧安装 | Jo-Bolt |
| 盲螺母板 | Rivnut |
| 仅剪切，低成本 | Hi-Shear |
| 复合材料 | LGPL |
