来源: NASA Fastener Design Manual, "Rivets and Lockbolts" (p.27-33) & Appendix C

| Truss (扁圆头) | 宽扁圆 |

## 实心铆钉 (Solid Rivets)

### 常用型号
- **AD铆钉**：2117-T4铝合金，最常用
- **DD铆钉**（"冰盒"rivet）：2017-T4铝合金，更高强度
  - **必须保持在~0°F**直到安装（时效硬化）
  - 7050-T73铝合金铆钉可替代DD铆钉

### 重要限制
- 实心铆钉为**过盈配合**膨胀安装
- **不可用于复合材料或纤维材料**（会导致孔表面分层）
- 首选用于铝和铝-钢组合连接

### Cherry Buck 铆钉
- 混合设计：95 ksi剪切强度钛合金厂头 + 延性钛/铌合金镦头端
- 惯性焊接连接
- 可用至**600°F**
- 镦头可成形，整体剪切强度接近95 ksi

### 其他特殊铆钉
| 类型 | 材料 | 剪切强度 | 温度 |
|------|------|----------|------|
| Monel铆钉 | 67%Ni+30%Cu | Fsu=49 ksi | 优于铝 |
| 钛/铌铆钉 | MIL-R-5674 | 50 ksi | 室温可成形，通常无需涂层 |
| Cherry E-Z Buck | 钛/铌 | 50 ksi | — |

## 盲铆钉 (Blind Rivets)

### 优势
1. 单侧可安装
2. 给定长度可用于一定厚度范围
3. 比实心铆钉安装快
4. 夹紧力更均匀
5. 操作者培训要求低

### 按安装方式分类

#### 1. 拉芯型 (Pull-Mandrel)
- 工具拉预切口锯齿芯轴
- 膨胀远端形成铆头
- 达到适当载荷时芯轴在切口处断裂

#### 2. 螺纹芯轴型 (Threaded-Stem)
- 内螺纹芯轴，外部加工平面供工具夹持旋转
- 头部通常六角形防止管体旋转
- 有单件体和两体式

#### 3. 驱动销型 (Drive-Pin)
- 驱动销撑开远端形成铆头
- 安装快但**不用于航空航天**
- 主要用于商业钣金

### Cherry 盲铆钉
- 带锁紧环的结构盲铆钉
- 有标准径和加大径（用于修复扩孔）
- 剪切强度≈AD实心铝铆钉
- 受MS33522限制（附录C）

### Cherry 铆钉材料
| 材料 | 最大剪切强度 (psi) | 最高温度 |
|------|-------------------|----------|
| 5055铝 | 50,000 | 250°F |
| 5056铝 | 50,000 | 250°F |
| 合金钢 | 50,000 | 900°F |
| 不锈钢 | 50,000 | 900°F |
| Monel | 55,000 | 900°F |
| Inconel 600 | 60,000 | 900°F |
| Inconel X-750 | 75,000 | 1400°F |

### Huck 盲铆钉
- 类似Cherry但可用更高强度材料
- 有/无锁紧环、沉头/凸头可选
- 盲侧套筒变形方式与Cherry不同

### Pop 铆钉
- 家用维修常见
- **不推荐用于关键结构应用**
- 芯轴有时安装后脱落
- 盲侧头部对称性差

## 管状铆钉 (Tubular Rivets)

### 类型
| 类型 | 特点 |
|------|------|
| 压缩管状 | 两件过盈配合，软材料/外观要求 |
| 半管状 | 孔深≤1.12×直径，接近实心铆钉 |
| 全管状 | 孔更深，更弱，可穿透软材料 |
| 金属穿透 | 类似半管状但柱强度更高，可自穿孔 |

## 其他类型

### 劈开铆钉 (Split/Bifurcated Rivets)
- 标准"家用维修"铆钉
- 体部锯开/劈开，尖端锋利自穿孔
- 用于皮革、纤维、塑料、软金属
- **不用于关键应用**

### Hi-Shear 铆钉
- 高强度碳钢/不锈钢/铝/钛销
- 墩粗的镦头 + 套筒（2024铝或Monel）
- **仅用于剪切应用**（套筒抗拉可忽略）
- 套筒可目视检查成形是否正确
- 部分被各类锁螺栓取代

### LGPL 轻量化沟槽比例锁螺栓
- 专为复合材料设计
- 加大头 + 加大套筒→降低接触应力
- 法兰套筒

## 铆钉选型建议

| 需求 | 推荐 |
|------|------|
| 铝结构连接 | AD实心铆钉 |
| 更高强度（冷藏保存） | DD"冰盒"铆钉 / 7050-T73 |
| 单侧安装 | Cherry/Huck盲铆钉 |
| 复合材料 | LGPL / 避免实心铆钉 |
| 高温应用 | Cherry Buck钛/铌 (600°F) |
| 不锈钢/钛连接 | Monel铆钉 |
| 非关键家用 | Pop铆钉 |
