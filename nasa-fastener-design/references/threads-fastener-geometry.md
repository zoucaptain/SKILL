# 螺纹与紧固件几何 — Threads and Fastener Geometry

来源: NASA Fastener Design Manual, "Threads" (p.16-17) & "Proper Fastener Geometry" (p.26)

## 螺纹配合等级

### UNJ 螺纹 (MJ 为公制)
- 用于**抗疲劳**螺栓
- 牙底圆角半径加大，减少应力集中
- 外螺纹UNJ与内螺纹UN或UNJ配合

### 螺纹等级
- **1A/1B**: 松配合，易装配，用于快速拆装
- **2A/2B**: 通用级，大多数商业紧固件
- **3A/3B**: 紧配合，用于精密定位
- **4/5/6**: 更紧配合，极少使用

## NAS/MS 螺栓编码规则

以 NAS1003 ~ NAS1020 为例：
- **最后两位数字** = 螺栓直径（十六分之一英寸）
  - 例：直径编码 "06" = 6/16 = 3/8"
- **第一个破折号后的数字** = 夹持长度（十六分之一英寸）
- **字母** = 头部/杆部钻孔标识
  - A = 无钻孔
  - B = 螺栓头钻孔
  - C = 杆部钻孔
  - D = 头和杆都钻孔
  - 等等
- **附加字母/数字** = 材料标识

> ⚠️ 此编码体系在所有MS/NAS标准中**并非严格执行**

## 螺栓头识别

- 每个制造商有不同标记系统
- 附录A收录了数百种"常见"螺栓的标记识别
- 假冒问题：Grade 8.2 硼钢被标为 Grade 8
  - Grade 8.2: 低碳(0.22%C)硼钢，室温硬度可达Grade 8
  - 但>500°F后强度急剧下降
  - Grade 8: 中碳(0.37%C)钢，800°F仍可用

## 夹持长度 (Grip Length)

- **标准设计准则**：夹持长度应确保**螺纹不在剪切面上**
- 如果找不到精确夹持长度，可通过调整垫圈厚度实现
- 螺纹不应承受剪力

## 螺栓头/螺钉头样式

常见头型：
- 六角头 (Hex)
- 扁圆头 (Button/Truss)
- 沉头 (Countersunk/Flat)：角度60°~120°，常用82°和100°
- 圆头 (Universal)
- 盘头 (Pan)
- 方颈头 (Carriage Bolthead)
- 内六角 (Socket Head)

## 剪切头与剪切螺母

- 航空航天通用规则：**紧固件以受剪为主设计**
- 剪切头/剪切螺母厚度约为正常的一半（减重）
- **绝不可用于受拉应用**
- 扭矩表值也需**减半**

## 边缘距与间距

- **标称边缘距**：≥ 2D（D为孔径）
- **最小边缘距**：≥ 1.5D
- **标称间距**：4D
- 薄材料：间距过小会导致屈曲(buckling)
- 厚材料：可放宽间距（只要密封不是问题）

## 编号紧固件直径计算

```
直径 = 0.060 + 0.013 × N
```
N = 编号 (4, 6, 8, 10, 12)

示例：8号紧固件 → D = 0.060 + 0.013(8) = **0.164 in**

## 近似剪切和bearing许用值

无具体数据时的估算：
- **合金钢/碳钢**：Fsu = 0.6 × Ftu
- **不锈钢**：Fsu = 0.55 × Ftu
- **Bearing 极限**：Fbu = 1.5 × Ftu
- **Bearing 屈服**：Fby = 1.5 × Fty
