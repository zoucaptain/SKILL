# 垫圈 — Washers

来源: NASA Fastener Design Manual, "Washers" (p.13-14)

## 1. Belleville 垫圈 (碟形弹簧垫圈)

- 锥形垫圈
- 主要用于**维持均匀拉力**，而非锁紧
- 未完全压平时，在螺栓接头中充当弹簧
- **无锯齿面时无显著锁紧能力**
- 锯齿面会损坏配合表面

- **并联**（图b）：增加弹簧刚度

## 2. 螺旋弹簧锁紧垫片 (Helical Spring Lockwasher)

- 梯形线绕成的螺旋，一圈
- 自由高度≈截面厚度的2倍
- 材料：硬化碳钢、铝、硅青铜、磷青铜、不锈钢、K-Monel

### ⚠️ 关键结论：**无效锁紧**
- 拧紧过程中充当弹簧
- 螺栓完全拧紧后**被完全压平**
- 此时等效于**实心平垫圈**
- **锁紧能力为零**
- **总结：此类锁紧垫片用于锁紧是无用的**

## 3. 齿形锁紧垫片 (Tooth/Star Lockwashers)

- 用于螺钉和螺母
- 齿呈扭曲构型，边缘锋利
- 一边咬入螺栓头（或螺母），另一边咬入配合面

### 优势与劣势
- **优势**：确实提供一定锁紧能力
- **劣势**：
  - 损坏配合表面
  - 划痕可能在**高应力紧固件**或**配合件**中引发裂纹
  - 增加**腐蚀敏感性**

## 4. 自调心垫圈 (Self-Aligning Washers)

- 与锥形面螺母配合使用
- 允许最大**8°**的螺母与承载面不对中

### 警告
- 重量代价大 + 成本代价大
- **应仅作为最后手段使用**
- 更好的替代方案：将配合面平行度控制在可接受范围内（SAE手册建议：20 μin）
