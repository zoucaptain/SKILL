# 螺纹嵌件 — Inserts

来源: NASA Fastener Design Manual, "Inserts" (p.14-16)

## 概述

嵌件是内外均为螺纹的特殊器件，外螺纹/凸缘/滚花锁在钻孔/模塑孔/攻丝孔中。

**用途**：
- 在软材料（塑料、有色金属）中提供**高强度、耐磨**的螺纹孔
- 修复滑丝的螺纹孔
- 航空航天：在软材料中使用小尺寸高强度紧固件以减重
  - 嵌件外螺纹比内螺纹大约1/8"直径
  - 例：10-32螺栓 ≈ 等效5/16-18螺母

## 分类

### 两大类
1. **外螺纹型**：靠外螺纹锁定
2. **非螺纹锁定型**：滚花、锯齿、槽、过盈配合

### 外螺纹型的三种子类
1. 钢丝螺套 (Wire Thread)
2. 自攻型 (Self-Tapping)
3. 实心套筒型 (Solid Bushing)

---

## 1. 钢丝螺套 (Wire Thread Insert — Heli-Coil)

- 精密菱形截面不锈钢丝绕制
- 同时形成外螺纹和内螺纹
- 略过尺寸→过盈配合
- 有**自由运行型**和**锁紧型**（变形线圈）
- 安装后在缺口处折断安装舌(tang)

### 优势
- 修复滑丝螺纹孔的**最常用**类型
- 需要**最小的**孔径扩大
- 如果空间允许，实心套筒嵌件更优选

---

## 2. 自攻嵌件 (Self-Tapping Inserts)

- 实心套筒型，外螺纹类似自攻螺钉
- 锁紧组合：
  - **Nylok塞**：尼龙塞锁紧
  - **Speedsert变形螺纹**：螺纹成型，无切削碎屑
- 仅可用于较软材料
- 螺纹成型嵌件**不产生切削碎屑**（优势）

---

## 3. 实心套筒嵌件 (Solid Bushing Inserts)

- 如果空间允许，**优于钢丝螺套**
- 结构更坚固

---

## 4. 铆螺母 (Rivnut)

-  tubular铆钉 + 内螺纹 = 现场变形的盲螺母板
- 头型：凸头、沉头、平头
- 变体：闭端、密封头、加强筋杆、六角杆、加强筋头
- 未螺纹管状部分需变形→材料必须延性→**强度较低**

### Rivnut材料
| 材料 | 标准处理 | 最小极限抗拉强度 |
|------|----------|----------------|
| 铝6053-T4 | 阳极氧化 | 205 psi |
| 钢 C-1108 | 镉镀0.0002" | 45,000 psi |
| 钢 4037 | 镉镀0.0002" | 65,000 psi |
| 不锈钢430 | 酸洗钝化 | 67,000 psi |
| 不锈钢305/Carpenter 10 | 机加工亮面 | 80,000 psi |
| 黄铜260 | 机加工亮面 | 50,000 psi |

### 安装步骤
1. 嵌件套在安装工具的芯轴上
2. 插入预钻孔
3. 芯轴回缩，拉动螺纹部分向盲侧→未螺纹区形成凸起
4. 牢固夹紧；芯轴旋出，留内螺纹完整

---

## 选型建议

| 需求 | 推荐 |
|------|------|
| 修复滑丝孔，最小扩孔 | 钢丝螺套 |
| 高强度+空间允许 | 实心套筒嵌件 |
| 软材料，无碎屑 | 螺纹成型自攻嵌件 |
| 盲螺母板 | Rivnut |
| 锁紧需求 | 变形线圈钢丝螺套 / Nylok塞 |
