# 设计准则 — Design Criteria

来源: NASA Fastener Design Manual, "Design Criteria" (p.21-26)

## 1. 紧固件组剪力计算

### 步骤
1. **找到组 centroid（形心）**：对称图案时为几何中心
2. **直接剪力**：Pc = R / n（R=总载荷，n=紧固件数）
3. **计算 Σr²ᵢ**：rᵢ 为各紧固件到形心的径向距离
4. **力矩载荷**：M = R × e（e=偏心距）
5. **单个紧固件的力矩贡献剪力**：Pe = Mr / Σr²ᵢ
6. **合成剪力**：Pc 和 Pe 矢量相加

> 如果紧固件面积不等，确定形心时需按面积加权。

## 2. 紧固件组拉力计算

- 类似剪力计算，但形心可能不是几何形心
- 需确定**中性轴**（拉压分界线）
- 螺栓拉力与其到支枢轴的距离成正比
- 力矩与各紧固件到支枢轴距离的平方和成正比
- **螺栓总预紧力应大于最大外加拉力**（防止接头松动/泄漏）

## 3. 剪力+拉力联合载荷

### 载荷比
```
Rs (或 R₁) = 实际剪力 / 许用剪力
Rt (或 R₂) = 实际拉力 / 许用拉力
```

### 交互曲线方程
| 保守度 | 方程 |
|--------|------|
| 最保守 | Rs + Rt = 1 |
| 中等 | R²s + R²t = 1 |
| 标准(MIL-HDBK-5) | R²s + R¹·⁶t = 1 |
| 最小保守 | R²s + R³t = 1 |

### 安全裕度 (Margin of Safety)
```
MS = 1/√(R²s + R²t) - 1
```
- **要求**：Rs + Rt < 1 才有正安全裕度
- 分别计算**屈服**和**极限**材料许用值，取最严苛值

> ⚠️ 交互曲线未考虑夹紧面摩擦力对剪力的减少作用。某些情况下摩擦力可显著减少螺栓剪力。

### 关键原则
- **剪力为主时不应施加高扭矩**（公式说明）
- 高预紧力产生的拉应力会降低剪切承载能力

## 4. 螺纹孔拉脱力计算

```
P = (2/3) × π × dm × Fs × L
```

其中：
- **P**: 拉脱载荷 (lb)
- **dm**: 螺纹孔中径 (= 螺纹节径)
- **Fs**: 材料极限或屈服剪切应力
- **L**: 螺纹啮合长度 (in)

**2/3 因子**：经验系数。如果螺纹完美配合应为 1/2（圆柱壳面积平分），用 2/3 考虑螺纹不匹配。

## 5. 紧固件组 bearing（承压）

- 螺栓剪力应**高于**被穿材料的 bearing 屈服强度
- 由于孔位公差/间隙，板材必须 bearing 屈服才能让所有螺栓均载
- 孔位越不精确，单个螺栓在载荷分布前承担的越多

### ⚠️ 螺栓与铆钉不可混用承載
- 铆钉通常过盈配合安装
- 铆钉会承担全部载荷直到板材或铆钉屈服→螺栓才分担
- 同样适用于螺栓+销钉（roll pins）组合

## 6. 边缘距与间距

| 参数 | 标称值 | 最小值 |
|------|--------|--------|
| 边缘距 | 2D | 1.5D |
| 间距 | 4D | — |

- D = 紧固件直径
- 薄材料：间距过小→屈曲
- 厚材料：可放宽间距（注意表面密封）

## 7. 材料强度估算

无具体数据时：

**剪切强度：**
- 合金钢/碳钢：Fsu = 0.6 × Ftu
- 不锈钢：Fsu = 0.55 × Ftu

**Bearing 许用值：**
- Fbu = 1.5 × Ftu（极限）
- Fby = 1.5 × Fty（屈服）

## 8. 假冒紧固件

- Grade 8.2 硼钢被标为 Grade 8 是最有据可查的案例
- Grade 8.2（低碳0.22%C硼钢）室温硬度可达Grade 8
- 但>500°F后强度急剧下降
- Grade 8（中碳0.37%C钢）可用至800°F
- 进口无厂标紧固件无法追溯
