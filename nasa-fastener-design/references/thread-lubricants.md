# 螺纹润滑剂 — Thread Lubricants

来源: NASA Fastener Design Manual, "Thread Lubricants" (p.8-10) & Table III

## 润滑剂汇总表

| 类型 | 设计温度上限 (°F) | 真空可用 | 备注 |
|------|-------------------|----------|------|
| 油/油脂 | 250 | ❌ 否 | 最常见；真空下沸腾挥发；每次高温后需重新涂 |
| 石墨 | 212~250 | ❌ 否 | 需水分（油/水）才润滑；真空下失水变磨料 |
| 二硫化钼 (MoS₂) | 750 | ✅ 是 | 最流行干润滑剂；>750°F变MoS₃（磨料） |
| Synergistic Coatings | 500 | ✅ 是 | 氟碳注入多孔金属基体，防腐+润滑 |
| Never-Seez | 2200 | ✅ 是 | 油挥发后留Ni/Cu/Zn不咬死氧化物；每次需重新涂 |
| Silver Goop | 1500 | — | 含20-30%银；不可用于铝/镁；极贵 |
| 螺纹锁固剂 (可拆型) | ~275 | — | Loctite等，兼防咬死/润滑；环氧树脂基 |

## 详细要点

### 油/油脂
- 最常见但温度受限≤250°F
- 真空环境下**不可用**（沸腾挥发）
- 良好的润滑+防腐（在限制内）

### 石墨
- "干"石墨实际是细碳粉，**需要水分**（油或水）才起润滑作用
- 最高温度受限于水分沸点
- 真空下失水后变**磨料**，损坏接头
- 干燥石墨有研磨性

### 二硫化钼 (MoS₂)
- 最流行的**干润滑剂**
- 真空环境可用
- **~750°F**时变为三硫化钼（MoS₃），是磨料而非润滑剂

### Never-Seez
- 最高2200°F（制造商数据）
- 油挥发后在螺纹间留下镍、铜、锌的不咬死氧化物
- 每次安装需重新涂
- NASA Lewis 测试确认满意

### Silver Goop
- 含20-30%银
- 最高1500°F
- **不可用于铝或镁**
- 因含银，极贵

### 螺纹锁固剂 (如Loctite)
- 可拆型（如Loctite 242）兼作防咬死剂和润滑剂
- 环氧基，最高~275°F
- 不可拆型（如Loctite 2719）用于防篡改
