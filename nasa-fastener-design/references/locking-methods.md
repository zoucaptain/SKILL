# 锁紧方法 — Locking Methods

来源: NASA Fastener Design Manual, "Locking Methods" (p.10-13)

## 内螺纹孔锁紧

### Spiralock 内螺纹
- 根部有**30°楔形斜面**
- 夹紧载荷下，外螺纹牙顶紧贴斜面
- 使振动引起的横向移动几乎不可能
- 螺栓可用标准螺纹，锁紧功能由内螺纹完成
- 适合**中等抗振**要求

## 锁紧螺母 (Locknuts)

### 1. 开槽锁紧螺母 (Split Beam)
- 顶部开槽，槽部螺纹直径缩小
- 自由旋入直到螺栓到达槽区
- 开槽"梁"段被螺栓向外偏转，产生摩擦力
- 楔形斜面抵抗横向移动

### 2. 变形螺纹锁紧螺母 (Deformed Thread)
- 航空航天**最常见**
- **优势**：
  - 一次成型
  - 温度范围仅受母材/镀层限制
  - 可重复使用约**10次**
- 螺纹局部变形，装配时恢复椭圆

### 3. Nylok 尼龙嵌件
- 尼龙丸嵌入螺纹
- 压缩产生反作用力→锁紧
- **限制**：最高~250°F
- 重新装配会快速损坏尼龙

### 4. 锁紧环+密封 (Locking Collar and Seal)
- 纤维/尼龙垫圈装在螺母顶部
- 过盈配合卡在螺栓螺纹上
- 提供密封防气体/水分泄漏
- **限制**：最高~250°F

### 5. 尼龙贴片 (Nylon Patch)
- 替代环/丸的省钱方法
- 粘结在螺母或螺栓螺纹上
- 用于短螺纹长度（钻孔会导致应力集中）

### 6. 槽顶螺母+开口销 (Castellated Nut)
- 通常6个槽
- 螺栓末端有通孔
- 拧紧后旋至最近槽位对齐→插入开口销
- 极适合**低扭矩**应用（如轮毂轴承）

### 7. 双螺母 (Jam Nuts)
- **不可靠**，专家对哪个螺母在下都有争议
- 内螺母拧太紧→先屈服；外螺母拧太紧→内螺母卸载
- 很难达到正确扭矩分配
- **仅在**拉杆(turnbuckle)上可用（不承受拉力）
- **推荐**：用专用锁紧螺母替代

### 8. 锯齿面螺母/螺栓头 (Serrated-Face)
- 锯齿面在最终拧紧时咬入承载面
- 不能与垫圈配合使用
- 不能用于易划伤/腐蚀的表面
- Durlock 180：需110%拧紧扭矩才能松开
- 抗振测试**优异**

### 9. 锁线 (Lockwiring)
- 劳动密集但用于**关键应用**（航空航天）
- 螺母有钻孔角；螺栓头部有通孔或钻孔角
- 双扭法锁线

### 10. 直接干涉螺纹 (Direct Interfering Thread)
- 螺纹根径加大，产生轻微过盈
- 常用于螺纹双头螺柱（半永久安装）
- 不用于螺栓/螺母（会损坏螺纹）

### 11. 锥形螺纹 (Tapered Thread)
- 小端直径锥形化
- 最后3-4牙产生干涉

### 12. 螺母板 (Nutplates)
- 盲螺母
- 可固定或浮动式
- 用于太薄无法攻丝的材料
- 主要用于航空航天（安装贵：至少3个钻孔+2个铆钉/个）

### 13. 锁紧胶粘剂 (Locking Adhesives)
- Loctite 242 = 可拆型；Loctite 2719 = 防篡改型
- 其他厂商：Bostik, ND Industries, Nylock, 3M, Permaloc
- 固化方式：
  - 单组分：薄层无空气时硬化
  - 双组分：混合压缩后硬化
- 兼密封功能
- **温度限制**：最好的450°F，最差的仅200°F

## 选型建议

| 需求 | 推荐 |
|------|------|
| 高温 (>250°F) | 变形螺纹螺母 / Spiralock / 锯齿面 |
| 可重复拆卸 | 变形螺纹螺母（~10次）|
| 密封要求 | 锁紧环螺母 / 锁紧胶粘剂 |
| 低扭矩固定 | 槽顶螺母+开口销 |
| 最高可靠性 | 锁线 |
| 中等抗振 | Spiralock / 变形螺纹 / 锯齿面 |
| 低成本 | 尼龙贴片 |

## ⚠️ 无效锁紧方法
- **普通螺旋弹簧锁紧垫片**（helical spring washer）：完全压紧后等效实心平垫，**锁紧能力为零**
- **双螺母(Jam nuts)**：扭矩分配不可预测，不可靠
