## 使用方法

将对应 skill 目录放入 OpenClaw 的 skills 目录即可使用：
```
C:\Users\yanyan.zou\.openclaw\workspace\skills\<skill-name>\
```

每个 skill 包含 `SKILL.md`（入口文件）和 `references/`（分类知识文件）。
